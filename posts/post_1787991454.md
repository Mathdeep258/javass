哦对了，学JS非常推荐vs code ，因为js有三个编写位置：

1.是直接在html文件里加入这个标签里面  
2.可以在其他标签的属性里用onclick，比如

```
<button onclick="alert('讨厌，你点我干嘛')">点我一下</button>
```

缺点是会耦合

3.就是在外部创建一个.js文件，然后用href超链接这个文件

说了这么多，简单而言就是你要看效果，看的其实是一个html网页文件，如果你没写完一个，保存然后拖入浏览器就很麻烦

这个时候你只要装一个**Live Server**插件，装好以后，直接在 HTML 文件上启动 Live Server，它会帮你启动一个本地网页服务器。

之后修改代码、保存，再回到浏览器刷新，就可以非常方便地看到效果。

十分推荐！！！
